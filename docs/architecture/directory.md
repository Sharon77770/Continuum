# Directory Structure

| Path | Responsibility | Owner | Dependencies |
| --- | --- | --- | --- |
| `apps/desktop/lib/app` | App root, theme, desktop navigation, and bundled UI translations | Desktop | Flutter, Riverpod |
| `apps/desktop/lib/core` | User-scoped path resolution for database, model/runtime storage, bounded file logging, and shared developer-tool providers | Desktop infrastructure | Dart IO, path, Riverpod |
| `apps/desktop/lib/features/library` | World library, world creation, and scenario import/export | Desktop | Application state |
| `apps/desktop/lib/features/library/application` | Built-in playable first-run sample World factory | Desktop application | `game_core` |
| `apps/desktop/lib/features/library/application/scenario_template_catalog.dart` | Four ready-to-play World scenario templates and fresh World instantiation | Desktop application | `game_core` |
| `apps/desktop/lib/features/models/domain` | Model descriptors, device/recommendation/selection values, and repository/runtime contracts | Model Platform domain | Dart IO, Dart only |
| `apps/desktop/lib/features/models/application` | Model list/download/import/discovery/cloud selection orchestration and injectable providers | Desktop application | Riverpod, model contracts |
| `apps/desktop/lib/features/models/data` | Model manifest, secure secrets, hardware probe, HF/OpenAI clients, streamed downloader, managed llama.cpp installer/process, Windows shutdown adapter, and unified Novel adapter | Desktop integration | Dart IO, Flutter plugins, `crypto` |
| `apps/desktop/lib/features/models/presentation` | Consumer Models screen with recommendations, local models, discovery, cloud, and Advanced actions | Desktop presentation | Flutter, application state |
| `apps/desktop/lib/features/library/domain` | First-run World seeding and scenario file contracts | Library domain | `game_core` |
| `apps/desktop/lib/features/library/data` | Native JSON scenario file selection and versioned format adapter | Library integration | `file_selector`, `world_format` |
| `apps/desktop/lib/features/studio` | Overview, lore, character, location editors and section shell | Desktop | Application state |
| `apps/desktop/lib/features/player` | Cinematic current-scene presentation, choices, free input, and history | Desktop | Flutter, novel application state |
| `apps/desktop/lib/features/novel/application` | Campaign creation/continue, turn lifecycle, validation, commit and autosave orchestration | Desktop application | `game_core`, `novel_system`, provider and repository contracts |
| `apps/desktop/lib/features/novel/domain` | Campaign and language model settings repository contracts and settings value | Novel domain | Dart only |
| `apps/desktop/lib/features/novel/data` | OpenAI-compatible HTTP transport used behind the unified provider adapter | Desktop integration | Dart IO |
| `apps/desktop/lib/features/settings` | Advanced custom provider preferences and developer diagnostics/controller/service for DB and model-runtime maintenance | Desktop | Flutter, Riverpod, SQLite FFI |
| `apps/desktop/lib/features/settings/data/language_preferences_repository.dart` | Persists and restores UI and default game language preferences | Settings data | Dart IO, JSON |
| `apps/desktop/lib/state` | Riverpod providers, locale selection, and UI-facing state coordination | Desktop | `game_core`, Flutter, Riverpod |
| `apps/desktop/lib/features/world/domain` | World definition repository contract | Desktop | `game_core` |
| `apps/desktop/lib/features/world/data` | SQLite schema, migrations and mapping for world definitions, campaigns, and provider preferences | Desktop | `game_core`, novel repository contracts, sqflite FFI |
| `apps/desktop/windows/runner` | Windows host window and Flutter engine bootstrap | Desktop platform | Flutter Windows embedding API |
| `scripts` | PowerShell Windows environment diagnostics and repeatable build/smoke commands | Development | Flutter, Dart, Visual Studio |
| `docs/development` | Windows development workflow and local storage policy | Project | None |
| `apps/desktop/windows/flutter` | Flutter Windows build integration | Desktop platform | Generated Flutter SDK artifacts |
| `packages/game_core/lib/src` | Renderer-independent world and story domain values | Game Core | Dart only |
| `packages/world_format/lib` | Versioned JSON scenario serialization and validation | World Format | Dart only; `game_core` |
| `packages/novel_system/lib` | Narrative schema validation, context builder, and playable-world validation | Novel System | Dart only; `game_core` |
| `docs/architecture` | Architecture, flow, module, state, and directory decisions | Project | None |

The workspace root `pubspec.yaml` coordinates the Dart packages. The Windows runner is generated by Flutter under `apps/desktop/windows`.
